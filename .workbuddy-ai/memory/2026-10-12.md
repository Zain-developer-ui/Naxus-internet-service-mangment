## 🐛 Login fail — bug NAHI tha

Login POST `500` de raha tha. Password ka masla laga, **magar tha nahi**:

```
Connection Timeout Expired ... [Post-Login] complete=13079
Error Number:-2, State:0, Class:11
```

SQL Server theek tha (`Users` = 6 rows), app ke connections `sys.dm_exec_sessions`
mein **0** (leak nahi). Yani **transient network timeout**. Python se seedha HTTP
login kiya to `POST 200` → `/Admin/Dashboard`, `NEXUS.Auth` cookie set — sab theek.

**Do gotchas jo isme se nikle (MEMORY.md mein bhi likhe):**

1. `page.click(sel, { noWaitAfter: true })` **POST abort kar deta hai** — server log
   mein `Operation cancelled by user`. Isi wajah se lagta raha ke login fail ho raha
   hai jabke server par sign-in ho chuka tha. Sahi tareeqa:
   `Promise.all([page.waitForNavigation({timeout:90000}).catch(()=>{}), page.click(...)])`
2. playwright-cli ka browser `user-data-dir: <in-memory>` hai — **cookies invocations
   ke darmiyan nahi rehti**. Login aur audit ek hi `run-code` call mein karo.
