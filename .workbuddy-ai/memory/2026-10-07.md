**N1 — Double active sidebar (user ka screenshot).** Asal wajah:
`wwwroot/js/navigation.js` ka `initActiveLink()` (line 120-129) khud
`active` class lagata hai `path.startsWith(href)` se. Server ka
`_Sidebar.cshtml` `IsActive()` already sahi kaam kar raha hai — **JS usay
override kar deta hai**.

`/Operations/Connections` pe `path = "/operations/connections"`:
- `/Operations` → `startsWith("/operations")` → **TRUE → active** (galat)
- `/Operations/Connections` → exact → **TRUE → active** (sahi)

Dono active. **Har nested route pe hoga**: `/Bills` vs `/Bills/Details`,
`/Retail/Dashboard` vs `/Retail/Search`.

Fix: `initActiveLink()` sidebar ke liye band karo (server already karta hai).
