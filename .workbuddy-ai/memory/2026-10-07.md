### Method notes

- `dotnet build` har baar `taskkill //F //IM NEXUS.Services.exe` + `dotnet.exe`
  ke baad — warna exe DLL lock karti hai (`MSB3027` / SIGTERM).
- Build ~2-3 min leta hai. `run_in_background: true` + `grep -E "error"` +
  `sort -u` — warna 100+ warnings output dubo deti hain.
- curl se antiforgery: `grep -o 'name="__RequestVerificationToken"[^>]*value="[^"]*"'`
  phir `sed 's/.*value="//;s/"//'`. Login field `AccountIdOrEmail` hai.
- Multi-role login test ke liye bash function + alag cookie jar per role.
- Razor `@if` ke andar `<section>` khol kar bhool jana → `RZ1006` / `RZ1025`
  ("else if block is missing a closing }"). Brace count karo.
- `Services/Feedback/FeedbackService.cs` mein `new Feedback` **namespace collision**
  deta hai (`NEXUS.Services.Feedback` namespace hai) → `Domain.Procurement.Feedback` likho.
