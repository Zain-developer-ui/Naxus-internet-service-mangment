## ASAL BUG: advance line do dafa lag rahi thi (15 Oct raat)

Zain ka screenshot: INV-2026-00001, **Total $(123.46)** — negative bill — aur
"Nothng to pay". Page khaali nahi tha, **bill hi ghalat thi**.

### Root cause
`ApplyAdvanceAsync` sirf `order.AdvanceRemaining` dekhta tha. Advance line
ban chuki hoti magar `AdvanceApplied` sirf `CreateAsync` par kam hota — aur
`PrepareDraftAsync` par nahi. Isliye **har naye period par advance dobara
credit** hota tha:

| Bill | Con | Rental | Advance line | Order ka AdvanceApplied |
|---|---|---|---|---|
| 8 (Oct, con 19) | 19 | −175 | **−175** | 350 |
| 11 (Nov, con 19) | 19 | −175 | **−175** | 350 ← wahi paisa dobara |

Aur bill 6 par `ApplyPendingChargesAsync` advance ke **baad** chalti hai —
replacement router 75 add hone se total −110 → tax bhi **negative** (−13.46).

### Fixes
1. `Common/Billing/BillCalculator.cs` — `ServiceTaxAmount` = tax on
   `Math.Max(0, TaxableAmount)`; `TotalAmount` = `Math.Max(0, ...)`. Bill
   kabhi credit note nahi banti.
2. `BillingService.ApplyAdvanceAsync` — do guard: `order.AdvanceApplied > 0`
   ho to skip, aur `HasAdvanceLineAsync(connectionId)` (koi bhi earlier bill
   mein advance line ho) to skip. **Advance ek connection par sirf ek dafa.**
3. Data repair (`.workbuddy-ai/tmp/fix-advance-overcredit.sql`,
   `restate-stale-bills.sql`):
   - Bill 6: advance line −500 → −315 (rental jitna), order 21 AdvanceApplied
     0 → 315, total **−123.46 → 84.18**
   - Bills 7/8/9/11: advance line dobara lagi thi, total 0 par restate
     (AmountPaid > 0 wale bills ko cursor script chhod deti hai)

## Guides: PDF -> HTML (Zain ne PDF reject kar diye)

Zain: "pdf bilkul bikar banaya hai design sahi nahi". reportlab ka render sach mein
kharab tha — tables collapse ho kar paragraph ban gaye the, code blocks prose mein
ghul gaye the. Wo khud convert karega, is liye **HTML do**.

Naya builder: `.workbuddy-ai/tmp/build-guide-html.py`. Markdown -> print-ready HTML
(cover page, generated TOC, A4 `@page` CSS, `break-after: avoid` headings,
`break-inside: avoid` tables/pre, accent-coloured header row).

**Do bugs jo isme phansne wale hain:**
1. **Code-span placeholder.** `stash` agar `\x00N\x00` bheje to emphasis regex
   `(?<!\w)\*` mein `\x00` word-char nahi hai — theek. Lekin `\*\*(.+?)\*\*` greedy
   variants se bachna parhta hai jab code span bold ke andar ho. Ab placeholder
   `\ue000N\ue001` (Private Use Area) hai aur bold regex non-greedy.
2. **Multi-line list items.** `.md` mein wrapped list items (continuation line 2-space
   indent) — parser har line ko alag `<li>` bana raha tha, aur `**bold across\nlines**`
   toot jata tha. Fix: `join_list_items()` — jo line `^\s+\S` se match kare aur pichli
   line `^\s*([-*]|\d+\.)\s+` ho, to join kar do.

Output: `deliverables/guides/NEXUS-{User-Manual,Developer-Guide,Installation-Guide}.html`
(tables: 17/17/9, code blocks: 5/46/38). Verify: leftover `**` = 0, leftover `|` = 0.

**PDF rakh diye hain** magar Zain inhe reject kar chuka hai — HTML hi asli deliverable
hai. `.md` sources bhi wahin hain (edit karke HTML dubara ban sakta hai).
