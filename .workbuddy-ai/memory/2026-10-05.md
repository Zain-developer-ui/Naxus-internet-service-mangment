## SRS padha (dono .doc documents)

Legacy OLE2 `.doc` files the — LibreOffice/Word nahi hai system par. Python se
UTF-16LE + ASCII runs extract kar ke text nikala. Method:
- koi bhi run jo `(?:\x20-\x7e\x00){3,}` match kare → UTF-16LE decode
- `[\x20-\x7e]{3,}` → Latin-1 decode
- dono ko byte-offset par merge karo, phir junk filter (word-char ratio > 0.75)
Extracted text `.workbuddy-ai/tmp/*.clean.txt` mein hai.

### Do asli bugs — ye yaad rakhna

**1. `EnableRetryOnFailure` + manual transaction = 500.**
`Program.cs` mein EF retry strategy on hai. Uske saath
`Database.BeginTransactionAsync()` use karo to EF `InvalidOperationException`
deta hai: *"The configured execution strategy does not support user-initiated
transactions."* Wajah: EF khud ke banaye transaction ko replay nahi kar sakti.

**Fix / pattern:** poora transaction `CreateExecutionStrategy().ExecuteAsync()`
ke andar likho. Ye ab har future transaction wale write path ke liye lazmi hai —
warna wahi 500 milega.

**2. `Normalise()` khaali string ko `""` deta tha, null nahi.**
Optional field ke liye `landline is null` check kabhi true nahi hua, is liye
Rule V1 (Dial-Up par landline lazmi) chup-chaap skip ho gaya. Teen Dial-Up
customers bina landline register ho gaye. Ab `Optional()` null deta hai,
`Required()` trim karta hai. **Sabak:** optional text field ke liye hamesha
`IsNullOrWhiteSpace` use karo, `is null` nahi.
