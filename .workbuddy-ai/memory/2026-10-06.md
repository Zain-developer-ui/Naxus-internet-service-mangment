Fix (abhi ke liye): DB se seedha reset kiya. **Pending**: ya to feature chalu

### Hasher ka gotcha (yaad rakho)

.NET 8 ka `PasswordHasher` **210,000** iterations use karta hai, purana
100,000 nahi. Hash ka doosra byte-group isi ko encode karta hai:
`AQAAAAEAAYag` = 100k, `AQAAAAIAAYag` = 210k. Haath se hash bana kar DB mein
daalna ho to 210k use karo, warna `VerifyHashedPassword` **Failed** dega.

Verified hash banane ka aasan tareeqa: chhota console project
(`Microsoft.Extensions.Identity.Core` 8.0.11) + `new PasswordHasher<object>()`.
